# BGU Helper

Небольшой учебный веб-проект для студента БГУ.

Проект показывает:

- текущую погоду в Минске;
- последние новости БГУ;
- расписание группы 7А;
- позволяет обновить новости кнопкой;
- позволяет загрузить расписание из Google Таблицы;
- сохраняет новости в PostgreSQL.

## Что используется

- Python
- FastAPI
- PostgreSQL
- psycopg
- requests
- aiohttp
- asyncio
- openpyxl
- HTML / CSS

## Как работает проект

При открытии сайта FastAPI:

1. асинхронно получает новости из базы PostgreSQL;
2. асинхронно получает текущую температуру в Минске через Open-Meteo;
3. эти две операции выполняются параллельно через `asyncio`;
4. загружает расписание, если оно уже было получено;
5. вставляет данные в HTML-страницу;
6. показывает готовую страницу в браузере.

## Новости

При нажатии кнопки **«Обновить новости»**:

1. Python отправляет запрос на сайт БГУ;
2. получает новости в формате JSON;
3. проверяет, какие новости уже есть в базе;
4. добавляет только новые новости;
5. после этого страница обновляется.

Новости выводятся из PostgreSQL и сортируются по дате от новых к старым.

## Источник новостей

Новости берутся с официального сайта Белорусского государственного университета:

`https://bsu.by/news/novosti-s`

## Погода

Погода получается через Open-Meteo API.

Для Минска используются координаты:

- широта: `53.9`
- долгота: `27.5667`

Для запроса используется `aiohttp`.

Получение погоды выполняется асинхронно.

## Расписание

Расписание загружается из Google Таблицы в формате XLSX.

Для загрузки файла используется `requests`, а для чтения Excel-файла — `openpyxl`.

После нажатия кнопки **«Загрузить расписание из гугл таблицы»**:

1. сервер скачивает XLSX-файл;
2. `openpyxl` открывает таблицу;
3. из таблицы выбирается расписание группы 7А;
4. данные сохраняются в памяти приложения;
5. расписание отображается на главной странице.

Расписание хранится в памяти программы, поэтому после перезапуска сервера его нужно загрузить заново.
